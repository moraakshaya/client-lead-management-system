# Client Lead Management System

## Features

- Lead Management
- Client Management
- Follow-Up Management
- Notes Management
- Dashboard Statistics

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose

## APIs

### Leads
POST /api/leads
GET /api/leads
PUT /api/leads/:id
DELETE /api/leads/:id

### Clients
POST /api/clients
GET /api/clients

### FollowUps
POST /api/followups
GET /api/followups

### Notes
POST /api/notes
GET /api/notes

### Dashboard
GET /api/dashboard/stats
